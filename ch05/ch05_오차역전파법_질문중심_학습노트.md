## 1 이 문서를 읽는 방법

이 문서는 교재의 절 순서보다 질문이 생긴 순서를 따른다. 먼저 역전파가 무엇을 보내는지 이해한 다음, 계산 그래프의 작은 계층을 보고, 마지막에 `TwoLayerNet` 전체 코드로 다시 조립한다. 코드가 길어져도 다음 세 가지만 확인하면 길을 잃지 않는다.

1. 지금 순전파에서 무엇을 계산하고 저장하는가
2. 역전파에서 들어온 `dout`을 어떤 국소미분으로 바꾸는가
3. 최종적으로 필요한 `dW`와 `db`가 어디에 저장되는가

### 먼저 잡을 한 문장

역전파는 순전파 값을 거꾸로 복원하는 계산이 아니다. 어떤 값을 조금 바꿨을 때 최종 Loss가 얼마나 바뀌는지를 나타내는 기울기를, Loss 쪽에서 입력 쪽으로 전달하는 계산이다.

## 2 역전파와 연쇄법칙의 직관

### 왜 모든 에지를 거슬러 가는가

> 내가 막혔던 질문: 순전파 때 각 요소가 결과에 얼마나 영향을 줬는지만 검사하면 되는 것 아닌가. 왜 계산 그래프의 에지를 전부 거슬러 가는가.

학습이 바꾸려는 값은 `W1`, `b1`, `W2`, `b2`처럼 여러 곳에 흩어져 있다. 각 매개변수에 대해 필요한 것은 그 값이 Loss에 미치는 민감도다. 예를 들어 `∂L/∂W1`은 `W1`을 아주 조금 바꾸면 Loss가 얼마나 바뀌는지를 뜻한다.

수치미분은 매개변수의 원소를 하나씩 `+h`, `-h`로 바꾸어 Loss 차이를 측정한다. 정확한 기준을 만들기에는 좋지만 매우 느리다. 역전파는 순전파를 한 번 실행한 뒤 계산 그래프를 뒤로 한 번 지나면서 모든 매개변수의 기울기를 함께 구한다.

| 구분 | 수치미분 | 오차역전파법 |
| --- | --- | --- |
| 계산 방식 | 각 원소를 조금씩 바꾸고 Loss 차이를 측정 | 각 계층의 국소미분을 뒤로 연결 |
| 장점 | 구현이 단순하고 독립적인 기준이 됨 | 빠르고 실제 학습에 사용 가능 |
| 단점 | 매개변수가 많으면 매우 느림 | 계층의 backward 구현이 틀릴 수 있음 |
| 주된 용도 | 기울기 검산 | 학습용 기울기 계산 |

### 뒤로 가는데 왜 나누지 않고 곱하는가

> 내가 막혔던 질문: `z=t²`라면 `z`의 증가량을 `t`의 증가량으로 나눈 것이 미분인데, 역방향으로 가면 나눠야 하지 않는가.

역전파에서 뒤로 보내는 것은 원래 값이 아니라 변화의 배율인 미분이다. `x → t → z → L`처럼 계산이 이어질 때, `x`의 작은 변화가 `t`에서 한 번 확대되거나 축소되고, 다시 `z`와 `L`을 지나며 또 확대되거나 축소된다. 연속된 배율은 곱해진다.

$$\frac{\partial L}{\partial x}=\frac{\partial L}{\partial z}\frac{\partial z}{\partial t}\frac{\partial t}{\partial x}$$

`∂L/∂x`를 말로 읽으면 “원인 `x`를 아주 조금 바꾸면 관찰하는 결과 `L`이 얼마나 바뀌는가”다. 분모는 바꾸는 원인이고 분자는 관찰하는 결과다. 역전파라는 이름은 계산값을 역산한다는 뜻이 아니라, 최종 결과의 미분을 뒤에서부터 계산한다는 뜻이다.

한 값이 여러 갈래의 경로를 통해 Loss에 영향을 주면 각 경로에서 돌아온 기울기를 더한다. 경로 안에서는 국소미분을 곱하고, 갈라졌던 경로가 다시 모이는 지점에서는 기울기를 합산한다.

### 계산 그래프가 필요한 이유

복잡한 식을 곱셈과 덧셈 같은 작은 노드로 나누면 각 노드는 자기 주변의 국소미분만 알면 된다. 사과 가격에 수량을 곱하고, 귤 금액을 더하고, 마지막에 세금을 곱하는 그래프를 생각해 보자.

사과 가격이 최종 금액에 미치는 영향은 경로에 있는 국소미분의 곱이다. 수량이 2개이고 세율을 포함한 배율이 1.1이라면 `1.1 × 1 × 2 = 2.2`가 된다. 사과 가격이 1원 오를 때 최종 금액은 약 2.2원 오른다는 뜻이다.

| 노드 | 순전파 | 역전파 규칙 |
| --- | --- | --- |
| 덧셈 | `z = x + y` | 들어온 기울기를 두 입력에 그대로 보냄 |
| 곱셈 | `z = x × y` | `x` 쪽에는 `y`, `y` 쪽에는 `x`를 곱해 보냄 |

## 3 MulLayer가 저장하는 정보

> 내가 막혔던 질문: `MulLayer()`를 변수에 담지 않으면 `forward()`와 `backward()`를 쓸 수 없는가. `forward()` 없이 `backward()`를 호출하면 왜 문제가 되는가. `backward(self, dout)`인데 왜 호출할 때는 인수를 하나만 넘기는가.

```python
class MulLayer:
    def __init__(self):
        self.x = None
        self.y = None

    def forward(self, x, y):
        self.x = x
        self.y = y
        return x * y

    def backward(self, dout):
        dx = dout * self.y
        dy = dout * self.x
        return dx, dy
```

`apple_layer = MulLayer()`를 실행하면 객체 하나가 만들어지고 `__init__()`이 자동으로 실행된다. 같은 객체의 `forward()`가 `x`와 `y`를 저장하고, 나중에 `backward()`가 그 값을 다시 사용한다. 따라서 다음 두 호출은 반드시 같은 객체를 대상으로 해야 한다.

```python
apple_layer = MulLayer()
price = apple_layer.forward(100, 2)
dapple, dcount = apple_layer.backward(1.1)
```

`MulLayer().forward(...)`를 실행한 다음 새로 만든 `MulLayer().backward(...)`를 호출하면 두 객체가 다르다. 두 번째 객체에는 `x`와 `y`가 저장되지 않았기 때문에 정상적인 역전파가 불가능하다.

메서드를 호출할 때 객체 자신은 `self`로 자동 전달된다. 그래서 정의는 `backward(self, dout)`이지만 호출은 `apple_layer.backward(1.1)`처럼 `dout` 하나만 적는다. `return`은 값을 호출한 곳에 돌려주는 것이고, `print`는 화면에 보여 주기만 한다.

## 4 ReLU와 mask

> 내가 막혔던 질문: ReLU 코드에서 왜 `mask`라는 말을 쓰며, 순전파의 mask가 역전파에 어떻게 쓰이는가.

```python
class Relu:
    def __init__(self):
        self.mask = None

    def forward(self, x):
        self.mask = (x <= 0)
        out = x.copy()
        out[self.mask] = 0
        return out

    def backward(self, dout):
        dout[self.mask] = 0
        return dout
```

`mask`는 파이썬 예약어가 아니라 “막을 위치를 표시한 지도”라는 뜻으로 붙인 변수명이다. `x <= 0`인 위치는 `True`, 나머지는 `False`가 된다.

ReLU의 국소미분은 입력이 0보다 크면 1이고, 0 이하면 0이다. 순전파에서 열려 있던 위치는 역전파 기울기를 그대로 통과시키고, 막혀 있던 위치는 0으로 만든다. MulLayer가 `x`, `y`를 저장했듯이 ReLU는 `mask`를 저장한다. 이 패턴은 “순전파에서 backward에 필요한 단서를 캐시에 남긴다”는 계층 구현의 공통 원리다.

## 5 Affine 계층과 배치 계산

### Affine의 역할

완전연결층의 순전파는 `XW + b`다. 입력을 펼친 행렬 `X`에 가중치 `W`를 곱하고 편향 `b`를 더한다. 배치 크기가 `N`, 입력 차원이 `D`, 출력 차원이 `H`라면 형상은 다음과 같다.

$$X(N,D)W(D,H)=Y(N,H)$$

| 값 | 형상 | 의미 |
| --- | --- | --- |
| `X` | `(N, D)` | N개 데이터의 입력 특징 |
| `W` | `(D, H)` | 입력 D개와 출력 H개를 잇는 가중치 |
| `b` | `(H,)` | 모든 데이터에 공통으로 더하는 편향 한 세트 |
| `out` | `(N, H)` | N개 데이터의 Affine 출력 |
| `dout` | `(N, H)` | 뒤 계층에서 넘어온 출력 쪽 기울기 |

### dx에 W T가 필요한 이유

> 내가 막혔던 질문: `dx = np.dot(dout, W.T)`에서 왜 `T`가 등장하는가. 정답 데이터 `t`와 관계가 있는가.

`.T`는 transpose, 즉 전치다. 정답 레이블 `t`와는 관계가 없다. 순전파에서 `X(N,D)`와 `W(D,H)`를 곱해 `(N,H)`를 만들었다. 역전파에서 `(N,H)`인 `dout`을 입력 형상 `(N,D)`로 돌려보내려면 `W.T(H,D)`가 필요하다.

$$dx=dout\,W^T$$

형상만 확인해도 이유가 보인다. `(N,H) · (H,D) = (N,D)`이므로 `dx`가 원래 `X`와 같은 형상으로 돌아온다. 의미로 보면 출력별 영향을 입력별로 다시 모으기 위해 같은 연결을 반대 방향으로 따라가는 것이다.

### dW와 db

$$dW=X^T\,dout$$

$$db=\sum_{i=1}^{N}dout_i$$

```python
class Affine:
    def __init__(self, W, b):
        self.W = W
        self.b = b
        self.x = None
        self.dW = None
        self.db = None

    def forward(self, x):
        self.x = x
        return np.dot(x, self.W) + self.b

    def backward(self, dout):
        dx = np.dot(dout, self.W.T)
        self.dW = np.dot(self.x.T, dout)
        self.db = np.sum(dout, axis=0)
        return dx
```

> 내가 막혔던 질문: 배치에서 `b`의 형상이 왜 `(H,)`이고, `db = np.sum(dout, axis=0)`은 왜 합인가. `b × 데이터 개수`를 계산하는 것인가.

`b(H,)`는 브로드캐스트되어 N개 데이터의 각 행에 똑같이 더해진다. 하나의 `b`가 N개 경로에서 공통으로 사용됐으므로, 역전파에서는 각 데이터가 만든 편향의 기울기를 배치 축으로 합친다. `axis=0`은 행 방향, 즉 데이터 축을 없애는 합이다. `db`는 `b × N`이 아니라 `∂L/∂b`다.

## 6 SoftmaxWithLoss와 교차 엔트로피 오차

### CEE와 y t는 다른 값이다

> 내가 막혔던 질문: 교차 엔트로피 오차도 `y - t`가 아닌가. 왜 역전파에서 `y - t`가 나오는가.

교차 엔트로피 오차 CEE는 순전파에서 계산하는 스칼라 Loss다.

$$L=-\sum_k t_k\log y_k$$

정답이 원 핫 벡터라면 정답 클래스의 확률만 남으므로 `-log(정답 확률)`과 같다. 예를 들어 `y = [0.1, 0.2, 0.7]`, `t = [0, 0, 1]`이면 CEE는 약 `0.357`이다.

`y - t`는 CEE 자체가 아니다. Softmax와 CEE를 하나의 계층으로 묶어 로짓 `a`에 대해 미분했을 때 얻어지는 기울기다.

$$\frac{\partial L}{\partial a}=y-t$$

위 예의 역전파 기울기는 `[0.1, 0.2, -0.3]`이다. 오답 클래스에는 양수가 전달되어 경사하강 시 로짓이 낮아지고, 정답 클래스에는 음수가 전달되어 로짓이 높아진다.

```python
class SoftmaxWithLoss:
    def forward(self, x, t):
        self.t = t
        self.y = softmax(x)
        self.loss = cross_entropy_error(self.y, self.t)
        return self.loss

    def backward(self, dout=1):
        batch_size = self.t.shape[0]
        return dout * (self.y - self.t) / batch_size
```

이 코드는 `t`가 `y`와 같은 형상의 원 핫 벡터라는 전제다. MNIST를 불러올 때는 `load_mnist(..., one_hot_label=True)`처럼 정답 형식을 맞춘다. 마지막 계층에서는 보통 `dout=1`이지만, 위 코드는 연쇄법칙을 그대로 유지하도록 들어온 `dout`도 곱한다.

### 왜 batch size로 나누는가

> 내가 막혔던 질문: 데이터 하나의 영향을 보려고 나누는가. 모든 데이터가 같은 영향을 준다고 보는 것인가.

각 데이터의 영향이 같다는 가정 때문에 나누는 것이 아니다. 배치 Loss를 합이 아니라 평균으로 정의했기 때문이다.

$$L_{batch}=\frac{L_1+\cdots+L_N}{N}$$

각 샘플의 서로 다른 기울기는 이미 `y - t`의 각 행에 들어 있다. `/ batch_size`는 평균 Loss의 미분에 붙는 `1/N`이다. 이렇게 하면 배치 크기가 달라져도 Loss와 기울기의 규모가 크게 흔들리지 않는다.

추론에서 클래스 번호만 필요하면 Softmax 전후의 최댓값 위치가 같으므로 `argmax` 전에 Softmax를 생략할 수 있다. 확률이 필요하면 Softmax를 사용한다.

## 7 TwoLayerNet 전체 구조

### 한 줄 계산 흐름

```text
x → Affine1 → ReLU → Affine2 → logits → SoftmaxWithLoss → Loss
```

MNIST 예에서는 형상이 보통 `(N, 784) → (N, 50) → (N, 10)`으로 흐른다. `50`은 클래스 수가 아니라 은닉층이 만드는 중간 특징 수이고, `10`이 숫자 클래스 수다.

### 클래스가 조립하는 것

```python
class TwoLayerNet:
    def __init__(self, input_size, hidden_size, output_size,
                 weight_init_std=0.01):
        self.params = {}
        self.params['W1'] = weight_init_std * np.random.randn(input_size, hidden_size)
        self.params['b1'] = np.zeros(hidden_size)
        self.params['W2'] = weight_init_std * np.random.randn(hidden_size, output_size)
        self.params['b2'] = np.zeros(output_size)

        self.layers = OrderedDict()
        self.layers['Affine1'] = Affine(self.params['W1'], self.params['b1'])
        self.layers['Relu1'] = Relu()
        self.layers['Affine2'] = Affine(self.params['W2'], self.params['b2'])
        self.lastLayer = SoftmaxWithLoss()
```

`params` 딕셔너리는 학습할 배열을 보관한다. `layers`는 순전파 순서대로 계층 객체를 조립한다. `OrderedDict`를 사용하면 `values()`를 순회할 때 `Affine1 → Relu1 → Affine2` 순서가 유지된다. `lastLayer`는 정답 `t`까지 필요한 손실 계층이라 예측용 계층들과 따로 둔다.

| 메서드 | 역할 |
| --- | --- |
| `predict(x)` | `layers`를 순서대로 순전파하여 로짓 반환 |
| `loss(x, t)` | `predict` 뒤 `SoftmaxWithLoss.forward`를 실행하여 Loss 반환 |
| `accuracy(x, t)` | 예측 클래스와 정답 클래스 비교 |
| `gradient(x, t)` | 순전파 캐시를 만든 뒤 전체 계층을 역전파하여 `dW`, `db` 수집 |
| `numerical_gradient(x, t)` | 매개변수 원소를 조금씩 바꾸며 수치미분 기울기 계산 |

### gradient가 self loss를 먼저 호출하는 이유

> 내가 막혔던 질문: `gradient()` 안에서 `self.loss(x, t)`를 호출하는 것은 순전파를 미리 계산해 놓는 것인가. 예제라서 넣은 것인가.

맞다. 이것은 예제용 장식이 아니라 역전파 전에 필요한 필수 준비다. 반환된 Loss 숫자를 사용하려는 것이 아니라 각 계층의 캐시를 채우려는 호출이다.

- Affine은 `self.x`를 저장한다.
- ReLU는 `self.mask`를 저장한다.
- SoftmaxWithLoss는 `self.y`와 `self.t`를 저장한다.

```python
def gradient(self, x, t):
    self.loss(x, t)          # 순전파와 캐시 저장

    dout = 1                # ∂L/∂L = 1
    dout = self.lastLayer.backward(dout)

    layers = list(self.layers.values())
    layers.reverse()
    for layer in layers:
        dout = layer.backward(dout)

    grads = {}
    grads['W1'] = self.layers['Affine1'].dW
    grads['b1'] = self.layers['Affine1'].db
    grads['W2'] = self.layers['Affine2'].dW
    grads['b2'] = self.layers['Affine2'].db
    return grads
```

역전파는 스칼라 Loss에서 시작하므로 처음 기울기는 `∂L/∂L = 1`이다. 이후 계층 순서를 뒤집어 한 계층씩 `backward()`를 호출한다. 각 Affine 객체가 계산한 `dW`와 `db`를 마지막에 `grads` 딕셔너리로 모은다.

## 8 loss W와 numerical gradient

### lambda가 하는 일

> 내가 막혔던 질문: `loss_W = lambda W: self.loss(x, t)`에서 lambda는 왜 필요한가. `W`를 얼마나 바꾸는지는 어디에 있으며, `loss_W`가 Loss 차이를 정의한 것인가. 인수 `W`는 왜 식에 직접 나오지 않는가.

```python
def numerical_gradient(self, x, t):
    loss_W = lambda W: self.loss(x, t)

    grads = {}
    grads['W1'] = numerical_gradient(loss_W, self.params['W1'])
    grads['b1'] = numerical_gradient(loss_W, self.params['b1'])
    grads['W2'] = numerical_gradient(loss_W, self.params['W2'])
    grads['b2'] = numerical_gradient(loss_W, self.params['b2'])
    return grads
```

`loss_W`는 Loss 차이를 계산하지 않는다. 현재 매개변수 상태에서 Loss를 한 번 평가하는 함수다. 다음 일반 함수와 같은 뜻이다.

```python
def loss_W(W):
    return self.loss(x, t)
```

실제 `+h`, `-h` 변경과 중앙차분은 바깥에 정의된 일반 함수 `numerical_gradient(f, x)`가 담당한다.

```python
def numerical_gradient(f, x):
    h = 1e-4
    grad = np.zeros_like(x)

    it = np.nditer(x, flags=['multi_index'], op_flags=['readwrite'])
    while not it.finished:
        idx = it.multi_index
        tmp = x[idx]

        x[idx] = tmp + h
        fxh1 = f(x)
        x[idx] = tmp - h
        fxh2 = f(x)

        grad[idx] = (fxh1 - fxh2) / (2 * h)
        x[idx] = tmp
        it.iternext()

    return grad
```

`self.params['W1']` 배열은 `numerical_gradient` 안에서 제자리 변경된다. Affine 계층도 같은 배열 객체를 참조하므로, `self.loss()`를 호출하면 변경된 값이 계산에 반영된다. lambda의 `W`가 본문에 직접 쓰이지 않아도 동작하는 이유다. 인수는 수치미분 함수가 요구하는 호출 규격을 맞추는 역할도 한다.

| 이름 | 역할 |
| --- | --- |
| `loss_W` | 현재 매개변수로 Loss를 평가하는 함수 |
| 일반 함수 `numerical_gradient(f, x)` | `x`의 각 원소를 `±h`로 바꾸고 중앙차분 계산 |
| 메서드 `network.numerical_gradient(x, t)` | `W1`, `b1`, `W2`, `b2`마다 일반 함수를 호출하는 관리자 |

### 같은 이름이 안팎에 있어도 되는 이유

> 내가 막혔던 질문: `numerical_gradient` 안에 또 `numerical_gradient`가 있는데 어떻게 가능한가. 자기 자신을 다시 부르는 재귀 호출인가.

서로 다른 이름 공간에 있는 두 함수다. `network.numerical_gradient(x, t)`처럼 객체 앞에 점이 붙은 호출은 `TwoLayerNet`의 메서드다. 메서드 안의 `numerical_gradient(loss_W, self.params['W1'])`에는 `self.`가 없으므로 모듈 수준의 일반 함수를 찾는다. 자기 메서드를 다시 호출하려면 `self.numerical_gradient(...)`라고 써야 한다.

## 9 기울기 검산

> 내가 막혔던 질문: `gradient_check.py`의 `network.gradient(x_batch, t_batch)`는 어디에서 정의된 것인가. `x_train[:3]`은 무엇인가.

`network.gradient(...)`는 `TwoLayerNet` 클래스 안에 정의한 역전파 메서드다. 기울기 검산에서는 같은 매개변수의 기울기를 두 방식으로 구해 비교한다.

```python
network = TwoLayerNet(input_size=784, hidden_size=50, output_size=10)

x_batch = x_train[:3]
t_batch = t_train[:3]  # t_train은 one_hot_label=True로 불러온 정답

grad_numerical = network.numerical_gradient(x_batch, t_batch)
grad_backprop = network.gradient(x_batch, t_batch)

for key in grad_numerical.keys():
    diff = np.average(np.abs(grad_backprop[key] - grad_numerical[key]))
    print(key + ':' + str(diff))
```

수치미분은 느리지만 계산 원리가 단순해 독립적인 기준으로 쓸 수 있다. 역전파는 빠르지만 코드 실수가 생길 수 있다. 두 결과의 평균 절댓값 차이가 매우 작다면 backward 구현이 올바를 가능성이 높다. 검산이 끝난 뒤 실제 학습에서는 빠른 `gradient()`를 사용한다.

`x_train[:3]`은 시작 인덱스를 생략해 0부터 시작하고, 인덱스 3 직전까지 선택한다. 즉 첫 번째, 두 번째, 세 번째 데이터만 가져온다. 수치미분이 느리기 때문에 작은 배치로 검산하는 것이다.

## 10 파이썬 문법 빠른 해석표

| 문법 | 기본 의미 | 이 장의 예 |
| --- | --- | --- |
| `()` | 함수나 메서드 호출, 클래스 객체 생성, 정의에서 매개변수 자리 | `MulLayer()`, `self.loss(x, t)` |
| `[]` | 리스트 생성 또는 리스트 배열 딕셔너리에서 값 선택 | `params['W1']`, `x[idx]` |
| `{}` | 딕셔너리 또는 집합 생성 | `grads = {}` |
| `.` | 객체의 속성이나 메서드에 접근 | `self.layers`, `W.T`, `layer.forward(x)` |
| `[:3]` | 처음부터 인덱스 3 직전까지 슬라이스 | 첫 3개 데이터 |
| `lambda` | 이름 없이 짧은 함수를 정의 | `lambda W: self.loss(x, t)` |

`self.layers['Affine1'].dW`는 왼쪽부터 읽으면 쉽다.

1. `self` 객체의 `layers`를 찾는다.
2. 딕셔너리에서 `'Affine1'` 객체를 꺼낸다.
3. 그 객체가 저장한 `dW`를 가져온다.

`for layer in self.layers.values()`의 `layer`는 반복문이 매번 꺼낸 객체를 잠시 담는 변수다. 예약어도 아니고 미리 선언해야 하는 이름도 아니다. `forward` 역시 파이썬이 자동 제공하는 특별한 이름이 아니라 각 클래스가 직접 정의한 일반 메서드다.

대소문자와 밑줄은 이름의 일부다. `lastLayer`와 `last_layer`는 파이썬에서 완전히 다른 변수다. 코드에서 두 표기가 섞여 있다면 오타이거나 서로 다른 코드 버전을 섞어 본 것인지 확인해야 한다.

## 11 한 페이지 멘탈 모델

### 한 문장으로 연결하기

순전파는 입력을 Loss까지 보내면서 각 계층이 backward에 필요한 단서를 저장하고, 역전파는 Loss에서 1로 출발해 각 계층의 국소미분을 적용하면서 `W`와 `b`에 대한 Loss의 민감도 `dW`, `db`를 얻는다.

```text
입력 x
  → Affine1  저장 x          역전파 dx = dout·Wᵀ  dW = Xᵀ·dout  db = Σdout
  → ReLU     저장 mask       역전파 x≤0 위치를 0으로 차단
  → Affine2  저장 x          역전파 같은 Affine 규칙 적용
  → SoftmaxWithLoss 저장 y,t 역전파 (y−t)/N
  → Loss
```

### 머릿속 실행 순서

1. `predict(x)`가 `Affine1 → ReLU → Affine2`를 실행해 로짓을 만든다.
2. `loss(x, t)`가 Softmax와 CEE를 실행하고 각 계층의 캐시를 채운다.
3. `gradient(x, t)`는 `dout = 1`에서 시작해 `SoftmaxWithLoss.backward()`를 먼저 호출한다.
4. 이어 `Affine2 → ReLU → Affine1`을 지난다. ReLU는 `mask`로 길을 막고, Affine은 `W.T`로 `dx`, `X.T`로 `dW`, 배치 합으로 `db`를 만든다.
5. 원 핫 정답에서 Softmax와 CEE의 로짓 기울기는 `(y - t) / N`이다. 역전파와 수치미분이 거의 같으면 검산에 성공한 것이다.

| 헷갈리는 표현 | 바로 떠올릴 뜻 |
| --- | --- |
| 역전파 | 값을 되돌리는 것이 아니라 Loss 민감도를 뒤로 전달 |
| 연쇄법칙 | 경로를 따라 변화율이라는 배율을 곱함 |
| `W.T` | 정답 `t`가 아니라 형상을 되돌리는 가중치 전치 |
| `db = sum(axis=0)` | 모든 데이터가 공유한 편향의 기울기를 배치 축으로 합침 |
| `(y - t) / N` | Softmax와 CEE를 합친 평균 Loss의 로짓 기울기 |
| `self.loss()` 선호출 | backward용 캐시를 만드는 순전파 |
| 두 `numerical_gradient` | 메서드는 관리자, 일반 함수는 중앙차분 계산기 |

### 막힐 때의 점검 순서

형상 → `self`에 저장된 캐시 → 현재 값이 Loss인지 기울기인지 → 점 앞의 객체 → 수치미분과의 차이를 차례로 확인한다.
