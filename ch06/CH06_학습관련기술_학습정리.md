## 1. Optimizer: 가중치를 어떻게 업데이트할 것인가?

신경망 학습의 기본 목표는 Loss를 줄이는 방향으로 파라미터 `W`, `b`를 업데이트하는 것이다.

기본적인 형태는 다음과 같다.

\[
W \leftarrow W - learning\_rate \times gradient
\]

여기서 gradient는 Loss가 증가하는 방향이므로 반대 방향으로 이동한다.

---

## 2. SGD

SGD는 현재 gradient만 보고 파라미터를 업데이트한다.

```python
params[key] -= self.lr * grads[key]
```

즉,

\[
W \leftarrow W-\eta\frac{\partial L}{\partial W}
\]

- `lr`: learning rate
- `grads[key]`: 현재 파라미터의 gradient

### 특징

구현은 단순하지만 Loss 함수의 모양에 따라 지그재그로 이동하거나 최적점까지 느리게 이동할 수 있다.

---

## 3. Momentum

Momentum은 이전의 이동 방향을 기억한다.

```python
class Momentum:
    def __init__(self, lr=0.01, momentum=0.9):
        self.lr = lr
        self.momentum = momentum
        self.v = None

    def update(self, params, grads):
        if self.v is None:
            self.v = {}

            for key, val in params.items():
                self.v[key] = np.zeros_like(val)

        for key in params.keys():
            self.v[key] = (
                self.momentum * self.v[key]
                - self.lr * grads[key]
            )

            params[key] += self.v[key]
```

핵심 식:

\[
v \leftarrow momentum \times v-lr\times gradient
\]

\[
W \leftarrow W+v
\]

### `v`란?

`v`는 이전까지의 이동 방향과 속도를 기억하는 값이다.

같은 방향의 gradient가 반복되면 이전 이동량이 누적되어 SGD보다 더 빠르게 이동할 수 있다. 반대로 gradient 방향이 바뀌면 기존 `v`와 새로운 이동 방향이 서로 상쇄될 수도 있다.

### `self.lr = lr`의 의미

```python
def __init__(self, lr=0.01):
    self.lr = lr
```

오른쪽 `lr`은 `__init__`으로 들어온 매개변수이고, 왼쪽 `self.lr`은 해당 객체가 계속 가지고 있을 인스턴스 변수이다.

즉:

```text
전달받은 lr 값
    ↓
self.lr에 저장
    ↓
다른 메서드에서도 사용 가능
```

## 4. AdaGrad

AdaGrad는 각 파라미터마다 지금까지 gradient가 얼마나 크게 발생했는지를 기억한다.

```python
class AdaGrad:
    def __init__(self, lr=0.01):
        self.lr = lr
        self.h = None

    def update(self, params, grads):

        if self.h is None:
            self.h = {}

            for key, val in params.items():
                self.h[key] = np.zeros_like(val)

        for key in params.keys():

            self.h[key] += grads[key] * grads[key]

            params[key] -= (
                self.lr * grads[key]
                / (np.sqrt(self.h[key]) + 1e-7)
            )
```

핵심은:

\[
h \leftarrow h+gradient^2
\]

그리고:

\[
W \leftarrow
W-
\frac{lr}{\sqrt h}
gradient
\]

이다.

### 왜 gradient를 제곱하는가?

gradient가 `+3`, `-3`일 때 단순히 더하면 서로 상쇄되지만 제곱하면 둘 다 `9`가 된다. 따라서 방향과 관계없이 **얼마나 큰 변화가 반복되었는지** 누적할 수 있다.

### AdaGrad의 핵심

`h`가 계속 커지면

\[
\frac{lr}{\sqrt h}
\]

가 작아진다. 따라서 자주 크게 움직였던 파라미터는 점점 조심스럽게 업데이트한다.

단, 너무 오래 학습하면 `h`가 계속 누적되어 learning rate가 지나치게 작아질 수 있다.

## 5. Hyperparameter란?

- `b`

## 6. 가중치 초기값을 왜 0으로 하면 안 되는가?

모든 W를 0으로 초기화하면 같은 층의 뉴런들이 동일한 계산을 한다.

그 결과 동일한 gradient를 받고 계속 동일하게 업데이트된다.

```text
뉴런 A: W = 0
뉴런 B: W = 0
뉴런 C: W = 0

→ 같은 출력
→ 같은 gradient
→ 같은 업데이트
→ 계속 똑같음
```

따라서 서로 다른 뉴런이 서로 다른 특징을 학습하지 못한다.

그래서 W에는 일반적으로 랜덤한 초기값을 사용한다.

주의:

- `W=0` 초기화는 문제가 될 수 있음
- Momentum의 `v=0`은 정상
- AdaGrad의 `h=0`도 정상
- bias를 0으로 초기화하는 것도 일반적으로 가능

`v`, `h`는 가중치가 아니라 과거 학습 정보를 저장하는 변수이기 때문이다.

## 7. `np.random.randn()`이란?

```python
np.random.randn(1000, 100)
```

은 평균 0, 표준편차 1인 정규분포에서 랜덤한 숫자를 뽑아 `(1000, 100)` 배열을 만든다.

예:

```python
x = np.random.randn(1000, 100)
```

- 데이터 1000개
- 각 데이터마다 특징 100개

## 8. 활성화값이란?

신경망에서:

```python
a = np.dot(x, W) + b
z = sigmoid(a)
```

- `a`: 활성화 함수에 들어가기 전 값
- `z`: 활성화 함수를 통과한 출력 = 활성화값

따라서 **은닉층의 활성화값 분포**란 은닉 뉴런들이 만들어낸 `z`들이 어느 범위에 얼마나 퍼져 있는지를 의미한다.

## 9. 가중치의 표준편차와 활성화값 분포

실험 코드:

```python
x = np.random.randn(1000, 100)

node_num = 100
hidden_layer_size = 5
activations = {}

for i in range(hidden_layer_size):

    if i != 0:
        x = activations[i-1]

    w = np.random.randn(node_num, node_num) * 1

    a = np.dot(x, w)
    z = sigmoid(a)

    activations[i] = z
```

흐름:

```text
x
↓
W1
↓
a1
↓
sigmoid
↓
z1
↓
다음 층의 x
↓
W2
↓
...
```

`activations[i]`에는 각 층의 활성화값을 저장한다.

---

## 10. 왜 여러 값을 더하면 분산이 커지는가?

독립적인 랜덤변수라면:

\[
Var(X+Y)=Var(X)+Var(Y)
\]

이다.

예를 들어 각각 분산이 1인 랜덤변수 100개를 더하면 대략:

\[
Var \approx 100
\]

이 된다.

신경망의 뉴런도:

\[
a=x_1w_1+x_2w_2+\cdots+x_nw_n
\]

처럼 많은 값을 더한다.

따라서 아무 조절 없이 입력 개수 `n`이 증가하면 출력의 분산도 커질 수 있다.

---

## 11. Xavier 초기값은 왜 `1/√n`인가?

입력의 분산이 1이라고 단순화하고, 가중치의 분산을 `Var(W)`라고 하면:

\[
Var(a)\approx nVar(W)
\]

층을 통과하기 전후의 분산을 비슷하게 유지하고 싶다면:

\[
nVar(W)\approx1
\]

따라서:

\[
Var(W)\approx\frac1n
\]

표준편차는 분산의 제곱근이므로:

\[
Std(W)=\frac1{\sqrt n}
\]

이 된다.

그래서:

```python
W = np.random.randn(...) / np.sqrt(node_num)
```

형태가 나온다.

즉 Xavier의 핵심은:

> 입력 연결 수가 많아질수록 합산으로 분산이 커지므로, 각각의 W를 그만큼 작게 만들어 신호의 크기를 유지한다.

## 12. std=0.01일 때 활성화값이 0에 치우친다는 의미

```python
W = 0.01 * np.random.randn(...)
```

이면 W가 0 근처의 아주 작은 값이 된다.

그러면:

\[
a=xW
\]

역시 작은 값에 몰리기 쉽다.

ReLU를 사용한다면:

```text
a = [-0.02, 0.01, -0.005, 0.03]

ReLU

z = [0, 0.01, 0, 0.03]
```

처럼 음수는 모두 0이 되고 양수도 작은 값이다.

따라서 **활성화값들이 0 근처에 집중된다.**

이것은 `W를 전부 0으로 초기화했다`는 뜻과는 다르다.

---

## 13. He 초기값

ReLU에서는 He 초기값이 잘 맞는다.

\[
Std(W)=\sqrt{\frac2n}
\]

Xavier는:

\[
\frac1{\sqrt n}
\]

He는:

\[
\sqrt{\frac2n}
\]

이므로 He가 조금 더 큰 초기 가중치를 사용한다.

이유는 ReLU가 음수 입력을 모두 0으로 만들기 때문이다.

```text
입력 분포
음수 | 양수
     ↓ ReLU
0으로 제거 | 양수만 통과
```

따라서 ReLU에 의해 신호가 줄어드는 효과를 고려하여 초기 가중치 크기를 더 크게 잡는다.

정리:

```text
Sigmoid / tanh → Xavier

ReLU → He
```

## 14. Batch Normalization

Batch Normalization은 mini-batch의 값을 정규화하여 각 층에서 값의 분포가 지나치게 변하는 것을 완화한다.

먼저 batch 평균:

\[
\mu_B=\frac1m\sum x_i
\]

분산:

\[
\sigma_B^2
=
\frac1m\sum(x_i-\mu_B)^2
\]

그리고:

\[
\hat{x_i}
=
\frac{x_i-\mu_B}
{\sqrt{\sigma_B^2+\epsilon}}
\]

로 정규화한다.

결과적으로 대략:

```text
평균 → 0
분산 → 1
```

인 기준 분포를 만든다.

---

## 15. BatchNorm의 γ와 β

정규화한 뒤:

\[
y=\gamma\hat{x}+\beta
\]

를 수행한다.

### γ (gamma)

정규화된 값의 크기를 확대/축소한다.

예:

```text
x̂ = [-1, 0, 1]

γ = 2

→ [-2, 0, 2]
```

### β (beta)

분포의 위치를 이동시킨다.

```text
[-2, 0, 2]

β = 3

→ [1, 3, 5]
```

즉:

```text
정규화
↓
안정적인 기준점 생성
↓
γ : 크기 조절
β : 위치 조절
↓
현재 층에 적절한 분포 학습
```

γ와 β 역시 학습되는 파라미터이다.

---

## 16. BatchNorm 계산 그래프의 `1/x` 노드

정규화 식:

\[
\hat{x}
=
\frac{x-\mu}
{\sqrt{\sigma^2+\epsilon}}
\]

에서 나눗셈을 다음처럼 바꿀 수 있다.

\[
\hat{x}
=
(x-\mu)
\times
\frac1{\sqrt{\sigma^2+\epsilon}}
\]

따라서 계산 그래프는:

```text
σ²
↓
+ ε
↓
√
↓
√(σ²+ε)
↓
1/x
↓
1/√(σ²+ε)
↓
× (x-μ)
↓
x̂
```

가 된다.

여기서 `1/x`의 x는 원래 데이터 `x`라는 변수명이 아니라,

> 입력받은 숫자의 역수를 계산하는 함수

라는 의미다.

예:

```text
입력 2 → 1/x → 0.5
입력 4 → 1/x → 0.25
```

이렇게 작은 연산으로 나누는 이유는 역전파를 계산하기 쉽기 때문이다.

\[
y=\frac1x
\]

의 미분은:

\[
\frac{dy}{dx}=-\frac1{x^2}
\]

이다.

## 17. 과대적합(Overfitting)

과대적합은:

> 훈련 데이터에는 매우 잘 맞지만 처음 보는 데이터에는 잘 맞지 않는 상태

이다.

책에서는 이를 관찰하기 위해 일부러 학습 데이터를 줄인다.

```python
x_train = x_train[:300]
t_train = t_train[:300]
```

그리고 충분히 큰 네트워크를 사용한다.

```python
hidden_size_list=[100, 100, 100, 100, 100, 100]
```

즉:

```text
학습 데이터 매우 적음
+
모델의 표현 능력 큼
+
같은 데이터를 계속 학습
↓
훈련 데이터 암기 가능
↓
train accuracy ↑↑
test accuracy는 상대적으로 낮음
```

이 차이가 과대적합을 보여준다.

## 18. `max_epochs = 201`

```python
max_epochs = 201
```

은 최대 약 201 epoch까지 학습하겠다는 실험 설정이다.

예를 들어:

```python
epoch_cnt += 1

if epoch_cnt >= max_epochs:
    break
```

처럼 사용한다.

- `epoch_cnt`: 현재 몇 epoch인지
- `max_epochs`: 최대 몇 epoch까지 할 것인지

따라서 `max_epochs`는 학습되는 파라미터가 아니라 사람이 정하는 설정이다.

## 19. Weight Decay

Weight Decay는 과대적합을 억제하기 위해 **너무 큰 가중치에 벌점을 주는 방법**이다.

원래 Loss:

\[
L_{data}
\]

에 다음 항을 추가한다.

\[
L_{total}
=
L_{data}
+
\frac{\lambda}{2}\sum W^2
\]

즉 모델에게:

```text
① 정답을 잘 맞혀라
+
② 하지만 W를 지나치게 크게 만들어
   억지로 맞히지는 마라
```

라는 두 조건을 동시에 주는 것이다.

### 왜 큰 W를 억제하는가?

큰 W는 특정 입력의 작은 변화가 출력에 큰 영향을 주도록 만들 수 있다.

훈련 데이터에만 우연히 존재하는 특징에 큰 가중치가 붙으면:

```text
훈련 데이터
→ 잘 맞음

처음 보는 데이터
→ 그 우연한 특징이 없음
→ 잘못 예측할 가능성 증가
```

따라서 큰 가중치를 전반적으로 억제하면 훈련 데이터의 미세한 특징에 지나치게 민감해지는 것을 완화할 수 있다.

단,

> 큰 W 하나 = 쓸데없는 특징 하나

라고 항상 1:1 대응하는 것은 아니다.

---

## 20. Weight Decay가 실제로 W를 줄이는 이유

벌점:

\[
\frac{\lambda}{2}W^2
\]

을 W로 미분하면:

\[
\lambda W
\]

이다.

따라서 gradient는:

\[
\frac{\partial L_{total}}{\partial W}
=
\frac{\partial L_{data}}{\partial W}
+
\lambda W
\]

가 된다.

업데이트하면:

\[
W
\leftarrow
W-lr
\left(
\frac{\partial L_{data}}{\partial W}
+
\lambda W
\right)
\]

이므로 W를 0 방향으로 당기는 효과가 발생한다.

```text
+10 → 0 방향
-10 → 0 방향
```

여기서 `weight_decay` 또는 λ는 벌점의 강도를 결정하는 하이퍼파라미터다.

## 21. Dropout

Dropout은 훈련할 때 뉴런을 랜덤하게 일부 제거한다.

```text
원래

● ● ● ● ● ●

훈련 1회

● X ● ● X ●

다음 훈련

X ● ● X ● ●
```

특정 뉴런 몇 개에 지나치게 의존하는 것을 방지하여 과대적합을 억제한다.

---

## 22. Dropout 코드

```python
class Dropout:
    def __init__(self, dropout_ratio=0.5):
        self.dropout_ratio = dropout_ratio
        self.mask = None

    def forward(self, x, train_flg=True):
        if train_flg:
            self.mask = (
                np.random.rand(*x.shape)
                > self.dropout_ratio
            )

            return x * self.mask

        else:
            return x * (1.0 - self.dropout_ratio)

    def backward(self, dout):
        return dout * self.mask
```

### `dropout_ratio`

```python
dropout_ratio = 0.5
```

이면 약 50%를 삭제한다.

### mask 생성

```python
np.random.rand(*x.shape)
```

으로 x와 같은 모양의 0~1 랜덤값을 만들고:

```python
> self.dropout_ratio
```

로 True/False를 만든다.

예:

```text
랜덤값
[0.7, 0.2, 0.9, 0.3]

dropout_ratio = 0.5

mask
[True, False, True, False]
```

그리고:

```python
x * self.mask
```

를 하면 False인 위치가 0이 된다.

---

## 23. Dropout에서 시험 때 생존 비율을 곱하는 이유

책의 구현에서는 훈련 때 뉴런을 제거하지만 시험 때는 모든 뉴런을 사용한다.

예를 들어 dropout ratio가 0.2라면:

```text
20% 삭제
80% 생존
```

훈련 때 출력이 10인 뉴런은 평균적으로:

\[
10(0.8)+0(0.2)=8
\]

정도의 출력을 만든다.

시험 때 모든 뉴런을 살리면 그냥 10이 되어 훈련 때보다 출력 규모가 커진다.

그래서 시험 때:

\[
10\times0.8=8
\]

로 맞춘다.

코드:

```python
return x * (1.0 - self.dropout_ratio)
```

즉:

> 시험 때는 모든 뉴런을 사용하되, 훈련 당시 뉴런의 생존 비율을 곱하여 훈련과 시험의 출력 규모를 맞춘다.

---

## 24. Inverted Dropout

현대 프레임워크에서는 보통 반대 방법을 많이 사용한다.

생존율이 0.8이라면 훈련 때:

\[
\frac1{0.8}=1.25
\]

를 살아남은 출력에 곱한다.

```text
Dropout으로 평균 출력
80
↓
× 1/0.8
↓
100
```

따라서:

```text
책의 방식

훈련 → 그대로 Dropout
시험 → × 생존비율


Inverted Dropout

훈련 → Dropout 후 ÷ 생존비율
시험 → 그대로
```

두 방법의 목적은 동일하다.

> 훈련과 시험에서 출력의 평균적인 크기를 맞추는 것.

## 25. 검증 데이터(Validation Data)가 필요한 이유

데이터의 역할을 세 가지로 나눈다.

```text
Training Data
→ W, b를 학습


Validation Data
→ learning rate, weight decay 등
  하이퍼파라미터 선택


Test Data
→ 최종 모델 성능 평가
```

Test 데이터를 보고 계속 하이퍼파라미터를 바꾸면 결국 Test 데이터에도 맞춰버릴 수 있다.

따라서 Test는 마지막까지 남겨두고 Validation 데이터를 따로 사용한다.

---

## 26. Validation 데이터 분리 코드

```python
(x_train, t_train), (x_test, t_test) = load_mnist()

x_train, t_train = shuffle_dataset(x_train, t_train)

validation_rate = 0.20

validation_num = int(
    x_train.shape[0] * validation_rate
)

x_val = x_train[:validation_num]
t_val = t_train[:validation_num]

x_train = x_train[validation_num:]
t_train = t_train[validation_num:]
```

### `shuffle_dataset()`

데이터의 순서를 섞는다.

단, x와 t의 대응 관계는 유지해야 한다.

### `shape[0]`

데이터 개수를 의미한다.

### `int()`

실수를 정수로 변환한다.

### `[:validation_num]`

처음부터 `validation_num` 전까지 가져온다.

### `[validation_num:]`

`validation_num`부터 마지막까지 가져온다.

따라서 60000개에서 validation rate가 20%라면:

```text
60000
↓ shuffle

12000 → validation
48000 → training
```

이 된다.

## 27. 하이퍼파라미터 최적화

하이퍼파라미터는 gradient로 학습하지 않고 여러 후보를 실제로 시험하여 Validation 성능으로 선택한다.

예:

```python
optimization_trial = 100

for _ in range(optimization_trial):

    weight_decay = \
        10 ** np.random.uniform(-8, -4)

    lr = \
        10 ** np.random.uniform(-6, -2)

    val_acc_list, train_acc_list = \
        __train(lr, weight_decay)
```

### `for _ in ...`

반복 횟수의 값 자체를 사용하지 않을 때 `_`라는 변수명을 관습적으로 사용한다.

### `np.random.uniform(-8, -4)`

-8 ~ -4 사이에서 랜덤한 실수를 뽑는다.

따라서:

```python
10 ** np.random.uniform(-8, -4)
```

는 대략:

\[
10^{-8}\sim10^{-4}
\]

범위에서 weight decay를 탐색한다.

하이퍼파라미터는 단순한 차이보다 10배, 100배 등의 크기 차이가 중요할 수 있기 때문에 이런 로그 스케일 탐색을 사용한다.

## 28. `results_val`에 왜 정확도가 여러 개 들어가는가?

예:

```python
results_val = {
    "lr:0.001, weight decay:0.0001":
        [0.12, 0.53, 0.76, 0.88]
}
```

하이퍼파라미터 조합 하나에 정확도 하나만 있는 것이 아니다.

같은 설정으로 여러 epoch를 학습하면서 매 epoch의 Validation accuracy를 기록하기 때문이다.

```text
lr = 0.001
weight decay = 0.0001

↓ 학습

epoch 1 → 0.12
epoch 2 → 0.53
epoch 3 → 0.76
epoch 4 → 0.88
```

따라서 `val_acc_list`는 학습 과정 전체의 정확도 기록이다.

---

## 29. `[-1]`의 의미

Python에서 음수 인덱스는 뒤에서부터 접근한다.

```python
values = [0.12, 0.53, 0.76, 0.88]
```

이면:

```text
values[0]  → 0.12

values[-1] → 0.88
values[-2] → 0.76
```

따라서:

```python
val_acc_list[-1]
```

은 **마지막 epoch의 Validation accuracy**를 가져온다.

## 30. `key=lambda x: x[1][-1]`

하이퍼파라미터 실험 결과가:

```python
{
    "설정 A": [0.2, 0.5, 0.85],
    "설정 B": [0.3, 0.7, 0.91],
    "설정 C": [0.4, 0.6, 0.87]
}
```

라고 하자.

`results_val.items()`를 사용하면:

```text
("설정 A", [0.2, 0.5, 0.85])
("설정 B", [0.3, 0.7, 0.91])
("설정 C", [0.4, 0.6, 0.87])
```

형태가 된다.

여기서:

```python
x[1]
```

은 정확도 리스트이고:

```python
x[1][-1]
```

은 그 리스트의 마지막 정확도다.

따라서:

```python
sorted(
    results_val.items(),
    key=lambda x: x[1][-1],
    reverse=True
)
```

는:

> 각 하이퍼파라미터 실험의 마지막 Validation accuracy를 기준으로 높은 순서대로 정렬한다.

는 의미다.

## 32. CH06에서 반드시 기억할 핵심

1. **Optimizer**
   - Gradient를 이용해 W를 어떻게 업데이트할지를 결정한다.
   - SGD는 현재 gradient만 사용한다.
   - Momentum은 이전 이동량 `v`를 기억한다.
   - AdaGrad는 과거 gradient²을 `h`에 누적하여 학습률을 조절한다.

2. **초기값**
   - W를 모두 0으로 만들면 뉴런들의 대칭성이 깨지지 않는다.
   - Sigmoid/tanh 계열에서는 Xavier가 적합하다.
   - ReLU에서는 He 초기값이 적합하다.

3. **Batch Normalization**
   - mini-batch의 분포를 정규화한다.
   - γ는 크기 조절, β는 위치 조절이다.
   - γ와 β도 학습된다.

4. **과대적합**
   - Training 성능은 매우 좋은데 새로운 데이터에 대한 성능이 떨어지는 현상이다.

5. **Weight Decay**
   - Loss에 큰 W에 대한 벌점을 추가한다.
   - 큰 가중치를 억제하여 지나치게 복잡한 학습을 완화한다.

6. **Dropout**
   - 훈련할 때 뉴런을 랜덤하게 제거한다.
   - 특정 뉴런에 지나치게 의존하는 것을 방지한다.

7. **Validation**
   - Train → W, b 학습
   - Validation → 하이퍼파라미터 선택
   - Test → 마지막 최종 평가

8. **하이퍼파라미터 최적화**
   - 처음부터 정확한 값 하나를 찾으려 하기보다 넓은 범위를 탐색한다.
   - Validation 결과가 좋은 범위를 찾고 점차 범위를 좁힌다.
